## วิธีได้ไฟล์ APK (ไม่ต้องลง Android Studio ในเครื่อง)

ใช้ **GitHub Actions** สร้าง APK ให้บนคลาวด์ แล้วโหลดมาลงมือถือ

### ขั้นที่ 1 — อัปไฟล์ขึ้น GitHub
1. สมัคร/ล็อกอิน https://github.com → กด **New repository** → ตั้งชื่อเช่น `autodrive` → **Create**
2. อัปไฟล์ขึ้น repo (เลือกวิธีใดวิธีหนึ่ง):
   - **แบบเว็บ (ไม่ต้องใช้ git):** หน้า repo → **Add file → Upload files** →
     ลากโฟลเดอร์ **`android`** และ **`.github`** (จาก `D:\AutoDrive`) ทั้งสองโฟลเดอร์เข้าไป → **Commit**
   - **แบบ git:** push โครงนี้ขึ้นไปตามปกติ
3. ต้องมีไฟล์ `.github/workflows/build-apk.yml` อยู่ใน repo (ตัว build อัตโนมัติ)

### ขั้นที่ 2 — ให้คลาวด์ build
- พอ commit เสร็จ ไปแท็บ **Actions** → จะเห็น workflow **"Build Android APK"** กำลังรัน
- ถ้าไม่รันเอง กด **Run workflow** ได้
- รอ ~3–6 นาที จนขึ้นเครื่องหมายถูกเขียว ✅

### ขั้นที่ 3 — โหลด APK
- คลิกเข้าไปใน run ที่เสร็จแล้ว → เลื่อนลงส่วน **Artifacts** → โหลด **`autodrive-apk`** (เป็น .zip)
- แตก zip จะได้ไฟล์ **`app-debug.apk`**

### ขั้นที่ 4 — ลงในมือถือ (sideload)
1. ส่งไฟล์ `app-debug.apk` เข้ามือถือ (สายUSB / Google Drive / LINE Keep ฯลฯ)
2. แตะไฟล์เพื่อติดตั้ง — ครั้งแรกจะขอเปิดสิทธิ์ **"ติดตั้งจากแหล่งที่ไม่รู้จัก"** ให้อนุญาต
3. เปิดแอป → อนุญาตกล้อง → ติดมือถือไว้หน้ารถ (แนวนอน) แล้วลองขับดูคำสั่งบนจอ

## ปรับแต่ง
- **ความแม่นของระยะ:** แก้ค่า `hfovDeg` ใน `Adas.kt` ให้ตรงมุมมองกล้องมือถือคุณ (ปกติ ~60–70°)
- **เกณฑ์เตือน:** ปรับ `safeDist / warnDist / critDist` ใน `Adas.kt`
- **คลาสที่ตรวจ:** EfficientDet-Lite0 รู้จัก 80 คลาส COCO (car, bus, truck, person, traffic light ฯลฯ)
