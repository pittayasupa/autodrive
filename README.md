# AutoDrive — Advisory ADAS (กล้องเดียว)

ระบบช่วยขับขี่แบบ **"แนะนำอย่างเดียว"** — รับวิดีโอจากกล้องหน้ารถ/dashcam
ตรวจจับ รถ / คน / ไฟจราจร ด้วย **YOLOv8**, ประมาณ **ระยะรถคันหน้า** ด้วยกล้องตัวเดียว
แล้วแสดงคำสั่งบนจอ (เลี้ยว / ชะลอ / เบรก / ไฟแดง)

> ⚠️ **ไม่ได้ควบคุมรถจริง** — แสดงผลบนหน้าจอเท่านั้น (advisory only)

## ไฟล์ในโปรเจค
| ไฟล์ | คือ |
|------|-----|
| `autodrive.py` | สคริปต์หลัก (detect + ประมาณระยะ + overlay) |
| `autodrive_mockup.html` | ตัวอย่างหน้าจอ (เปิดในเบราว์เซอร์ดูได้เลย ไม่ต้องลงอะไร) |
| `requirements.txt` | ไลบรารีที่ต้องติดตั้ง |

## ขั้นที่ 1 — ติดตั้ง Python (เครื่องนี้ยังไม่มี)

**วิธีง่ายสุด:** โหลดจาก https://www.python.org/downloads/ (เลือก 3.11 หรือ 3.12)
> ‼️ ตอนติดตั้ง **ติ๊ก "Add Python to PATH"** ด้วย

ตรวจสอบหลังลง (เปิด PowerShell ใหม่):
```powershell
python --version
```

## ขั้นที่ 2 — ติดตั้งไลบรารี
```powershell
cd D:\AutoDrive
python -m pip install -r requirements.txt
```
(ครั้งแรกจะดาวน์โหลด PyTorch ~รวมหลายร้อย MB ใช้เวลาสักพัก)

## ขั้นที่ 3 — รัน
```powershell
# 1) ใช้วิดีโอตัวอย่าง (โหลด dashcam จาก Pexels อัตโนมัติครั้งแรก)
python autodrive.py

# 2) ใช้วิดีโอของคุณเอง
python autodrive.py --source "C:\path\to\your_video.mp4"

# 3) ใช้เว็บแคม / กล้องจริง
python autodrive.py --source 0

# 4) เซฟผลลัพธ์เป็นไฟล์ (ไม่เปิดหน้าต่าง — เหมาะกับเครื่องช้า)
python autodrive.py --save output.mp4 --no-show
```
ระหว่างเล่น:  **Q** = ออก   **SPACE** = หยุด/เล่นต่อ

## ปรับแต่งให้ระยะแม่นขึ้น
ระยะคำนวณจากสูตร pinhole: `distance ≈ (focal × ความสูงจริง) / ความสูงกล่อง(px)`
ตัวแปรสำคัญคือ **มุมมองกล้องแนวนอน (HFOV)** ของกล้องคุณ:
```powershell
python autodrive.py --hfov 70     # กล้องมุมกว้างใส่ค่ามากขึ้น
```
> เพื่อความแม่นจริงจัง ควร calibrate กล้อง (หา focal length + มุมก้ม) ครั้งเดียว

## ตัวเลือกอื่น
| ธง | ความหมาย | ค่าเริ่มต้น |
|----|----------|------------|
| `--model` | โมเดล (`yolov8n/s/m.pt`) ใหญ่ขึ้น = แม่นขึ้นแต่ช้าลง | `yolov8n.pt` |
| `--conf` | ความมั่นใจขั้นต่ำ | `0.35` |
| `--imgsz` | ขนาด inference | `640` |
| `--max-width` | ย่อจอแสดงผล | `1100` |

## ข้อจำกัด (ตามตรง)
- **ระยะเป็นค่าประมาณ** จากกล้องเดียว ไม่เท่าเรดาร์/LiDAR — คลาดเคลื่อนได้โดยเฉพาะวัตถุที่ถูกบัง
- **ความเร็วรถ** เป็นค่าจำลอง (ไม่มี GPS/OBD) — ต่อ GPS หรือ OBD-II ทีหลังได้
- บน **CPU** ด้วย `yolov8n` ได้ราว ~5–15 FPS ขึ้นกับเครื่อง (มี GPU NVIDIA จะเร็วขึ้นมาก)
- ฟอนต์บนวิดีโอเป็นอังกฤษ (OpenCV วาดไทยไม่ได้) — อยากได้ไทยต้องใช้ PIL + ฟอนต์ไทย

## ก้าวต่อไป
- เทรน/ใช้โมเดลตรวจ **เลนถนน** (LaneNet, Ultra-Fast-Lane) เพื่อสั่งเลี้ยวจากความโค้งเลนจริง
- ใช้ **MiDaS / Depth-Anything** ประมาณ depth ทั้งภาพให้แม่นขึ้น
- ส่งคำสั่งออกเสียง (TTS) แทนข้อความบนจอ
